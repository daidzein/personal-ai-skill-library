# AGENTS.md

## Repository Instructions

This repository is a personal AI knowledge
and skill library.

### General Rules

- Treat README.md as the main index.
- Treat catalog/ as a registry, not proof
  of installed capabilities.
- Treat skills/ as reusable agent instructions.
- Treat references/ as supporting documentation.
- Treat upstream repositories as the source
  of truth for external tools.

### Documentation Rules

When adding a new skill or tool:

1. Create a catalog entry.
2. Include the original repository URL.
3. Document its purpose.
4. Document installation requirements.
5. Document supported platforms.
6. Include security considerations.
7. Record the last verification date.

### Engineering Rules

Follow the Karpathy methodology:

- Think before coding.
- Keep solutions simple.
- Make surgical changes.
- Verify the goal.

### Research Rules

When using external sources:

- Prefer original documentation.
- Verify time-sensitive information.
- Include source links.
- Do not fabricate capabilities.

### Security Rules

- Never commit API keys.
- Never commit passwords.
- Never commit browser cookies.
- Never commit private authentication data.
- Review external scripts before execution.
