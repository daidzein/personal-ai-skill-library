# personal-ai-skill-library

A centralized knowledge base, skill registry, and
tool directory for my AI agents.

This repository serves as a shared reference for
ChatGPT, OpenAI Codex, OpenCode, and other AI agents.

The objective is to build a reusable AI ecosystem
where knowledge, tools, workflows, and instructions
can be maintained independently from individual
AI platforms.

---

## Quick Start

New AI session? Start here.

**[START HERE — Universal Session Initialization](session-templates/START-HERE.md)**

Use this template to initialize ChatGPT, Codex,
OpenCode, or other compatible AI agents.

It instructs the agent to:

- Read repository instructions.
- Identify relevant skills.
- Check tool availability.
- Report dependencies.
- Follow documented methodologies.

## Core Objectives

1. Maintain reusable AI skills and instructions.
2. Collect useful open-source AI tools and repositories.
3. Build a shared knowledge base for multiple projects.
4. Standardize AI agent workflows.
5. Reduce repetitive context-setting across sessions.
6. Maintain documentation and installation references.

## Operating Principles

Every AI agent using this library should:

1. Read the relevant documentation before starting.
2. Identify which skills and tools are relevant.
3. Avoid loading unrelated references.
4. Verify external information against original sources.
5. Never assume that a tool is installed merely
   because it appears in this catalog.
6. Never execute unknown scripts without reviewing
   their contents.
7. Keep project-specific knowledge separate from
   universal instructions.

---

## How To Use This Library

Before starting a new task:

1. Identify the relevant project.
2. Review the relevant catalog entries.
3. Load applicable skill instructions.
4. Check whether required tools are installed.
5. Execute the task using the relevant methodology.
6. Document useful findings and reusable workflows.

---

## Maintenance

When adding a new tool or skill:

- Add a catalog entry.
- Include the original GitHub repository.
- Document installation requirements.
- Document dependencies.
- Identify supported AI agents.
- Include security considerations.
- Record the last verification date.

---

## Philosophy

This repository is not tied to a specific AI model.

It is a persistent knowledge and capability layer
that can be reused across different AI agents.

The AI model may change.
The knowledge, workflows, and engineering practices
should remain reusable.
